# INBREEDING_RENDER

**How Did Ancient Humans Avoid Inbreeding?** — cloud render package for the
canonical `INBREEDING/` production. 92 shots, 16,142 frames (8:58) at
1920×1080 30fps, rendered on GitHub Actions as 8 parallel chunks and stitched
into one mp4.

The source of truth is the original `INBREEDING/` folder — this package is a
verbatim copy of its Remotion project (`video/`) plus this render pipeline.
Re-copy from `INBREEDING/` if the edit ever changes.

## How the render works

```
.github/workflows/render-inbreeding.yml
  plan      → verify assets, split into 8 chunks at shot-cut boundaries → chunks.json
  render×8  → matrix job: remotion render Main --frames=<range> (swiftshader GL)
  combine   → concat + single x264/AAC re-encode → out/final_video.mp4 (uploaded artifact)
```

Key properties:

- **Shot-aligned seams** — chunk boundaries snap to real shot start frames
  (±⅓ chunk tolerance), so chunks are contiguous non-overlapping frame ranges
  and the stitch is frame-exact. No overlap/trim/dissolve tricks.
- **Fails fast** — `verify-assets.mjs` gates the render: every image/sfx/audio
  reference in `scenes.json` must exist, and the 92 shots must tile the
  timeline with zero gaps. `combine-chunks.mjs` re-checks every chunk duration
  and the final duration before declaring success.
- **Audio travels with the picture** — voiceover/music bed are pinned to the
  master timeline, so each chunk renders the correct audio window for free.

## Local use

```bash
cd INBREEDING_RENDER
node scripts/verify-assets.mjs          # asset + timeline gate
node scripts/plan-chunks.mjs            # writes chunks.json (default 8 chunks)
cd video && npm ci && cd ..
node scripts/render-chunk.mjs 0         # render chunk 0 → video/out/chunks/
node scripts/combine-chunks.mjs         # needs all chunks → video/out/final_video.mp4
```

Local renders work without `--gl=swiftshader` too (Remotion picks angle per
`remotion.config.ts`); swiftshader is what the CI runners need.
